# CanIFly Instagram promotion (drive to canifly.org)

**Goal:** clicks to [canifly.org](https://canifly.org) — not follows.  
**Boost first:** [Post 1](https://www.instagram.com/p/Dbk4HckiKK5/) (Limited / “Can I fly here?”).

### Blocked from Boost?
If Instagram says *“Because you subscribed to use Meta Products without ads, you can’t create ads”*:

1. **Organic-only (recommended for launch week)** — skip paid; use §2 below (Stories + replies + shares). Still drives the link in bio.
2. **Re-enable ads (optional)** — Meta → **Ad preferences** / Accounts Center → manage **Meta subscription without ads** → cancel or pause for the Instagram/Facebook account you use for CanIFly. Wait until ads are allowed again, then use §1. You may need a **Professional** account + payment method.

Do not fight the paywall mid-launch — organic is enough for day one.

---

## 1. Paid — boost Post 1 (when ads are allowed)

### Checklist
1. Open Post 1 → **Boost** / **Promote**
2. Objective: **Website visits** / **Traffic** (not Profile visits / Followers)
3. Destination URL: `https://canifly.org`
4. Confirm profile link is also `https://canifly.org`
5. Do **not** boost Posts 2 and 3 in the same test

### Audience (narrow)
| Setting | Value |
|--------|--------|
| Locations | Spain, Germany, France, Denmark, Switzerland, Portugal, Austria, Czechia, Poland, Sweden, Ireland, Latvia |
| Age | 18–45 |
| Interests (pick 3–5) | Drones, DJI, Aviation, Photography, Travel |

Avoid worldwide / “automatic” broad if it expands outside these countries.

### Budget
- **€5–10 / day** for **3–5 days**
- Pause if link CTR is weak after ~48h; scale only the winner
- Later: test Post 2 (Restricted) as creative B — not at the same time as Post 1

### Ad text (if IG allows a promo caption)

```
Can I fly here?

Tap the map for Clear / Limited / Restricted / Prohibited — by drone class and ceiling.

Live UAS zones across Europe.
→ canifly.org
```

### Call to action button
Prefer **Learn more** or **Visit website** (not “Follow”).

## 2. Organic — same day / this week

### Story (post today)
1. Upload the Limited screenshot (or Post 1 crop)
2. Add **Link** sticker → `https://canifly.org`
3. Text overlay (short):

```
Can I fly here?
→ canifly.org
```

### Comment replies (copy/paste)
Use on every meaningful comment:

```
Thanks — try it here: canifly.org
```

```
Planning aid only — always double-check with your CAA. Map: canifly.org
```

```
Yes — tap a point, set class & ceiling: canifly.org
```

### Share Post 1 (where allowed)
- 2–3 drone / UAS / pilot Facebook groups that allow product links
- Relevant Discord #promo or #showcase only if rules allow self-promo
- Always lead with the site URL, not “follow my IG”

### Optional Reel (10–15s)
| Time | Action |
|------|--------|
| 0–2s | Map open, pin visible |
| 2–8s | Tap → Limited card (“Clear to fly up to ~60m…”) |
| 8–12s | Quick pan over red zones |
| 12–15s | End card: **canifly.org** |

Caption:

```
Can I fly here? Tap the map.

Clear / Limited / Restricted / Prohibited — by class & ceiling.

→ canifly.org (link in bio)
```

## 3. Week-1 success metrics

| Priority | Metric |
|----------|--------|
| Primary | Link clicks / sessions on canifly.org (IG insights + Vercel/analytics) |
| Secondary | Saves + shares on Post 1 |
| Ignore | Follower count unless it tracks with clicks |

Review after day 2 and day 5 of the boost. Keep or kill based on **cost per link click**, not likes.

## 4. Avoid

- CTA that says “Follow this account”
- Worldwide audience (budget outside live coverage)
- Claiming official clearance — reply: planning aid; confirm with CAA / AIS
- Boosting all three posts at once
